# Zvuk Glass для Android

Неофициальный плеер для [Zvuk](https://zvuk.com) на Android: интерфейс в духе Spotify и Яндекс Музыки, скруглённые панели и эффект «жидкого стекла». Фон и акцентные цвета подстраиваются под обложку текущего трека.

Это отдельный проект. Версия для Windows живёт в репозитории [zvuk-glass](https://github.com/GhostOFFantasy/zvuk-glass), у неё свои номера версий и свои обновления.

## Установка

Скачайте `Zvuk-Glass-Android.apk` со страницы [Releases](https://github.com/GhostOFFantasy/zvuk-glass-android/releases/latest) прямо на телефоне и откройте его. Android попросит разрешить установку из этого источника. Нужен Android 7 или новее (ARM64 или ARMv7).

### Обновления

Приложение само проверяет GitHub при запуске и каждые 4 часа и тихо скачивает новую версию. Нажмите **«Установить»** и подтвердите установку в окне Android. Обновление ставится только поверх версии, подписанной тем же ключом: подменённый файл Android не примет.

## Вход

Пароль от Zvuk приложению не нужен. Оно работает с токеном вашей сессии:

1. В браузере телефона войдите на zvuk.com.
2. Откройте `https://zvuk.com/api/tiny/profile`, выделите весь текст и скопируйте.
3. В приложении нажмите **«Вставить»**. Токен найдётся сам.

Токен хранится только на телефоне и зашифрован ключом из Android Keystore. Резервное копирование данных приложения запрещено.

## Возможности

- «Моя волна» с настройками, волны редакции, радио по исполнителю, треку или альбому.
- «Популярное»: чарт «Топ 100», чарты и хиты, артисты и релизы из чарта, подборки редакции.
- Поиск, страницы исполнителя (все популярные треки), альбома и плейлиста, коллекция и плейлисты, лайки, история.
- Тексты песен с синхронизацией; если в Zvuk текста нет, он берётся из открытой базы LRCLIB.
- Полноэкранный плеер с 3D-каруселью, визуализатором, клипами с YouTube, мини-эквалайзером.
- Эквалайзер на 10 полос с пресетами и компрессором.
- **Музыка в фоне** и при погашенном экране. В уведомлении и на экране блокировки есть обложка и кнопки ⏮ ⏯ ⏭, кнопки гарнитуры тоже работают.
- **Жесты**:
  - плеер: смахнуть вниз — свернуть; влево или вправо по обложке — следующий или предыдущий трек;
  - мини-плеер: вверх — открыть плеер; влево или вправо — переключить трек;
  - очередь и текст: потянуть шапку вниз — закрыть;
  - долгое нажатие на трек — меню.
- **«Назад»** (кнопка или жест от края) закрывает открытое по шагам. На главной сворачивает приложение, музыка продолжает играть.

## Для разработки

Нужны Node.js, Rust с целями Android (`rustup target add aarch64-linux-android armv7-linux-androideabi`), Java 17+ и Android SDK с NDK (по умолчанию `D:\Android\Sdk`).

```
npm install
npm test               # проверочный APK для ARM64 → dist/android/Zvuk-Glass-<версия>-test.apk
npm run build          # ARM64 + ARMv7 → dist/android/Zvuk-Glass-<версия>.apk
npm run release        # выпуск: +1 к последней цифре версии
npm run release -- 3   # +3 (по числу изменений)
```

APK подписывается ключом `%USERPROFILE%\.tauri\zvuk-glass-android.jks`, пароль лежит рядом в `zvuk-glass-android.properties`. **Сохраните копию обоих файлов**: без них установленные приложения не примут обновление.

Мобильный интерфейс можно проверить и на компьютере. Сборка для Windows с ключом `--mobile-preview` открывает узкое окно с телефонным интерфейсом, касания имитируются через DevTools. Пример: `scripts/screenshots.ps1 -Only m-home,m-gest`.

```
src-tauri/src/          Rust (общий с версией для Windows код, части под Android — *_other.rs, mobile.rs, updates_android.rs)
src-tauri/gen/android/  Android-проект: MainActivity (отступы, «Назад»), MediaService (фон, уведомление),
                        ZgPlugin (мост к Rust), ZgSecrets (Android Keystore)
src/renderer/           интерфейс; mobile.js — жесты, «Назад», отступы; стили телефона — body.mobile в styles.css
scripts/android.mjs     сборка APK (обходит символическую ссылку Tauri без «режима разработчика» Windows)
scripts/release.mjs     выпуск
```

## Ограничения

- API Zvuk неофициальный. После обновлений сервиса что-то может перестать работать.
- Нет своих обоев и видео на фоне и автосинхронизации клипа по звуку: это есть только в версии для Windows.
